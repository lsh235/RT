It created synthetic docs, mappings, judgments, a saved concept, and an owner/foreign-account boundary, then deleted its synthetic ES index. It exercised a baseline tie, not a real-world quality improvement.

The first adversarial harness attempt updated an existing current validation judgment's query fingerprint, thereby changing an in-scope input. That attempt is invalid evidence and is not counted. These were harness-only corrections; no application code or tests were changed by QA.

The first browser/package smoke pass found stale v1.13.0 assertions in `scripts/browser_smoke.mjs` and `scripts/package_smoke.py`; these were reported as a round 2 fix finding. After the coordinator updated those checks, the complete browser suite and package smoke were rerun independently and passed. The earlier failures are recorded as pre-fix evidence only and do not affect the final R09 gate status.
