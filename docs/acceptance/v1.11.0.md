## User problem and fixed scope

The workbench currently hard-codes `intfloat/multilingual-e5-large` and a 1024-dimensional `rag_embedding`. Users cannot select another local model, inspect a full embedding recipe, or tell whether cached vectors and query vectors belong to compatible spaces.

R06 introduces a small, explicit profile registry for shared-index and account-private vector retrieval. It retains the existing E5 defaults and adds `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` as a second locally executable profile. Each profile records its model/source identity, resolved model revision or artifact digest, runtime version, dimension, similarity, input prefixes, and context/tokenizer limits. A profile change must never silently reuse vectors from another profile. The API and UI report missing optional dependencies, missing cache, download failure, and incompatible mapping with safe next steps. BM25 stays usable without downloading vector models.

The selection is intentionally bounded to these two profiles. User-supplied arbitrary model names, remote embedding providers, hosted inference, and retrieval-quality claims are outside R06. R06 validates actual local vector generation and compatibility, not that one profile ranks better than another; that belongs to the judged evaluation stages.

## Evidence limits

A successful model load or dimension check proves only that the selected local runtime produced a vector with the expected shape. It does not establish semantic usefulness, Korean retrieval quality, or improvement over another profile. The two model outputs occupy incompatible vector spaces even if future models share dimensions; only matching recorded profile recipes may be queried against stored vectors. No profile comparison or quality claim is accepted without the later fixed judged evaluation data.

The project license does not relicense downloaded model weights. The current profile metadata reports model licenses for user review; users remain responsible for checking model/source terms before distribution or use.
