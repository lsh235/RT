## Fixed scope

Improve the novice path through Elasticsearch connection, field selection, first search, saving a relevance judgment, and guidance for comparing retrieval modes. Keep the workbench local-first and preserve the existing advanced workflows.

- Clearly distinguish the supplied sample corpus/index from a user's real index. Importing sample data remains a separate explicit action and never overwrites an existing index.
- Let users save and select named connection profiles for non-secret settings. Do not persist passwords, API keys, authorization headers, or credentials embedded in endpoint URLs. Explain what is saved and where.
- Provide actionable recovery guidance for an unreachable or invalid endpoint, empty index, insufficient permissions, and vector search that is not ready.
- Separate Korean and English UI strings and translate the primary connection, search, result, and recovery screens.
- Improve keyboard navigation, visible focus, labels/status announcements, and narrow-screen layout.
- Keep novice guidance distinct from advanced settings without removing existing capabilities.
- Map the first-use/private-knowledge guidance to `docs/cycle45-48-roadmap.md`; do not claim that the later Cycle 46–48 search, ingestion, or evaluation requirements are complete in R03.
