## Goal and evidence boundary

R08 adds account-scoped, versioned evaluation datasets and makes relevance metrics auditable. Existing 25-document Jira data and Q01–Q10 evaluation remain regression fixtures only; they are not a representative retrieval-quality benchmark. The feature implementation must be useful with synthetic or user-authorized datasets, while the release record must distinguish synthetic, public-qrels, human-judged, and AI-suggested material. AI suggestions are never silently promoted to ground truth.

No third-party sample/query/qrels material may be bundled or redistributed based on the project-code Apache-2.0 license. Separate permission evidence has been offered by the user but has not yet been supplied or verified. R08 must not copy that material. Record dataset rights/source metadata and leave public-data quality gates NOT RUN when authorized data is unavailable.

Initial qrels source check: the [NFCorpus upstream terms](https://www.cl.uni-heidelberg.de/statnlpgroup/nfcorpus/) say the dataset is free for academic purposes and direct other uses to the included source terms and corpus author. The [BEIR repository](https://github.com/beir-cellar/beir#-disclaimer) says its public-dataset hosting does not establish that a user has a license to use each dataset. A derived [BEIR NFCorpus dataset card](https://huggingface.co/datasets/BeIR/nfcorpus) displays CC BY-SA 4.0, but that does not resolve the upstream terms for this project's redistribution context. No NFCorpus query, qrel, or document content is included or treated as permission-cleared here; seek rights-holder clarification before any redistribution or quality claim using it.

## Metric semantics fixed for this version

- A query/qrel entry is identified by dataset version, query ID, concrete index name, and concrete document ID. Display position or Elasticsearch hit order is not identity.
- A numeric grade is an explicit judgment. An explicit `null` judgment is unjudged. An absent query-document qrel is also unknown; the UI and metric output must keep it distinguishable from a numeric grade of zero.
- The default policy is `judged_only`: remove unjudged retrieved documents while preserving the relative order of numerically judged hits, then calculate ranking metrics on that judged ranking. For `P@k`, the denominator is `min(k, number of numerically judged hits returned)`; judged coverage is `numerically judged hits returned at k / all hits returned at k`. Explicit-null and absent qrels count as unjudged. The result includes separate counts for numeric judgments, explicit-null qrels, and absent qrels.
- `Recall@k` uses the number of explicitly judged relevant documents for that query as its denominator. `MRR@k` uses the first relevant rank in the judged ranking. `nDCG@k` uses graded gains on that same ranking and the ideal ranking of all explicitly judged documents for the query. Persist the relevance threshold used for binary metrics (default: grade >= 2 on the existing 0–3 scale), cutoffs, formulas, and denominators.
- A query with no explicitly judged relevant documents has Recall/MRR/nDCG reported as unavailable with a reason and is excluded from those macro denominators. `P@k` with no judged hits is unavailable. No unavailable value is rewritten as zero. Any policy that includes unjudged candidates as non-relevant requires an explicit named choice, an explicit dataset assertion that qrels are complete, and visible recording in results/exports.
- For a query with one or more known relevant qrels but no relevant hit in the returned ranking, Recall, MRR, and nDCG are numeric `0`; MRR is unavailable only when the query has no explicitly judged relevant documents.
- Split validation rejects equal normalized query strings and deterministic near-duplicates (character-trigram Jaccard >= 0.80), as well as matching explicit `information_need`, `related_query_group`, or qrel-level `document_family_id` values across splits. Manual group labels remain necessary for paraphrases that a lexical threshold cannot detect; report this limit rather than calling the check semantic.
