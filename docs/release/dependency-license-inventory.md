## 한국어 요약

`requirements-dev.lock`은 기본 및 개발용 11개 배포판의 해시와 정확한 버전을 고정하지만 라이선스 필드는 없습니다. 별도 격리 설치에서 수집한 exact-version metadata와 `dist-info/licenses` 파일은 표에 경로와 함께 기록했습니다. npm lock에는 Playwright 및 Playwright Core 1.64.1의 Apache-2.0 값이 있습니다.

선택 extra는 Python 3.12에서 해석했고 `agents`는 marker 경계 확인을 위해 3.10/3.11에서도 해석했습니다. 정확한 direct/transitive 배포판 이름·버전, wheel URL/hash, metadata 및 license/notice 파일 경로는 `dependency-audit/`의 JSON에 있습니다. 버전 범위가 고정된 lock이 아니므로 이 스냅샷을 재현 가능한 공급망 잠금으로 보지 않습니다. metadata 또는 라이선스 파일 누락이 남아 의존성 고지 감사는 **INCOMPLETE**입니다. `py_rust_stemmers==0.1.8` metadata는 `UNKNOWN`이지만 포함된 LICENSE 파일은 MIT License와 Qdrant 저작권 문구를 표시합니다. `UNKNOWN`은 라이선스 판정이 아닙니다.

두 샘플 파일은 setuptools의 wheel package-data 설정과 Dockerfile 빌드 입력에 모두 포함됩니다. 독립 QA는 wheel과 Docker image에서 두 샘플 파일의 실제 포함과 소스와 일치하는 바이트 hash를 확인했습니다. 증거 manifest는 [`dependency-audit/`](dependency-audit/README.md) 아래에 있습니다. 반복 wheel/Docker 빌드의 같은 호스트·도구 범위 결과와 나머지 R11 검증은 [독립 QA 보고서](../acceptance/v1.16.0-independent-qa.md)에 있습니다. 샘플의 별도 허가는 확인되지 않았으므로 재배포 권리 gate는 **UNRESOLVED / NOT RUN; blocker**입니다. 원격 모델/토크나이저 자산은 cache-only로 취급하며 프로젝트에 재배포되지 않습니다.
