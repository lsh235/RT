## 한국어 요약

프로젝트 소스 코드는 Apache-2.0을 선언하지만, 이는 번들 gRPC Jira 이슈 본문이나 매핑 JSON의 권리를 결정하지 않습니다. 두 파일은 현재 setuptools의 wheel package-data 설정에 걸리고 Dockerfile도 `COPY es_rag_tuner ./`로 파일이 든 디렉터리를 이미지 빌드 입력에 포함합니다. 그러므로 별도 재배포 허가가 확인되지 않은 상태에서 현재 공개 배포 구성에 실제 blocker가 있습니다. 독립 QA는 wheel 및 Docker image에서 두 파일의 포함과 소스와 일치하는 byte hash를 확인했습니다. 증거 manifest는 [`dependency-audit/`](dependency-audit/README.md) 아래에 있습니다. 별도의 R11 QA 보고서에는 같은 호스트·도구 설정에서 반복 빌드가 일치한 결과도 기록됩니다. 별도 허가 증빙은 아직 받거나 검증하지 않았으므로 권리는 **UNRESOLVED / NOT RUN**입니다. GitHub 이슈가 공개되어 있다는 사실은 재배포 허가가 아니며, GitHub 약관 인용은 증거 경계 설명일 뿐 법률 판단이 아닙니다. 승인된 별도 패키징 변경 또는 허가 확인 전에는 샘플을 배포하지 마세요.

Python 기본/dev lock에는 11개 exact package가 있으나 lockfile 자체에 license field는 없습니다. 독립 QA가 별도 설치에서 수집한 metadata에 따르면 9개는 `License-Expression`, `pluggy` 및 `pytest`는 legacy `License` 필드를 가지며, 11개 모두 dist-info license 파일이 수집되었습니다. 선택 extra는 Python 3.12에서 각각 설치 해석했고 `agents`는 Python 3.10/3.11 marker까지 확인했지만, 일부 배포판에 license metadata 또는 파일이 없습니다. 세부 exact resolution 및 evidence는 [`dependency-license-inventory.md`](dependency-license-inventory.md)와 repository-resident [`dependency-audit/`](dependency-audit/README.md)를 참조하세요. Optional 의존성 고지 감사는 **INCOMPLETE**이며 metadata/files 수집은 릴리스에 고지가 포함됐다는 증명이 아닙니다.
