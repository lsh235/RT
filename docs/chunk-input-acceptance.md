## Fixture scope

`tests/test_chunk_input_acceptance.py` uses synthetic dictionaries and an HTTP server with one stubbed document GET. `tests/run_chunk_input_fixture.py` serves synthetic in-memory document data on a dynamic loopback port and stubs the Elasticsearch request function. Neither contacts a production or test Elasticsearch cluster, loads the embedding model, or opens SQLite. Ports 8765 and 8766 remain untouched; no user database or credentials are used.
