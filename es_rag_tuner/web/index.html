3

평가 질의와 정보 요구 묶음

평가 질의는 실제 검색에 쓰는 문장입니다. 같은 정보 요구 묶음 이름을 반복하면 여러 문장 표현을 함께 셉니다. 이름이 비어 있으면 각 질의는 별도 묶음입니다.

같은 사용 방식의 기존 묶음 이름을 입력할 때 제안을 볼 수 있습니다. 재사용은 선택 사항이며, 빈칸으로 두거나 새 이름을 자유롭게 입력해도 됩니다.

각 질의를 별도로 검색하고, 성공한 질의마다 독립된 미리보기 기록을 저장합니다. 문서 평가도 선택한 질의 ID별로 따로 유지됩니다.

질의를 선택하면 문서 평가가 저장됩니다.

선택

AI에게 초안이나 결과 해석 요청

사용할 수 있는 구독에 로그인되어 있으면 초안을 제안합니다. 결과 확인과 저장은 직접 선택합니다.

연결 상태 확인 중
AI 기능은 선택 사항입니다. 로그인할 수 없더라도 직접 개념을 만들고 검색 결과를 평가할 수 있습니다.

예: “요청 시간 초과 후 복구한 사례를 찾고 싶어요. 현재 결과에서 빠진 이유도 확인해 주세요.”

AI의 응답은 검색 결과에 대한 모델 해석입니다. 문서의 관련성이나 답변 품질을 증명하지 않으므로 직접 확인하세요. AI는 선택한 인덱스에서 허용된 문서만 읽습니다. 저장, 평가, 설정 적용은 할 수 없습니다. 문서 내용은 신뢰할 수 없는 자료로 취급합니다.

결과에 없는 문서 찾기와 확인

문서 ID를 몰라도 제목이나 본문에서 기억나는 단어로 후보를 찾을 수 있습니다. 찾기는 저장된 개념의 제목·본문 필드만 사용하며, 저장 질의의 조건이나 개념 필터는 적용하지 않습니다. 후보를 평가 대상으로 선택한 뒤 관련성을 직접 판단하세요.

최대 10개 후보를 보여줍니다. 결과 없음은 선택된 필드에서 이번 찾기가 일치 항목을 반환하지 않았다는 뜻이며, 문서가 인덱스에 없다는 뜻은 아닙니다.

후보 모아 보기 · BM25 + 벡터

저장한 질의로 기존 벡터 임베딩을 검색해 BM25 후보와 한 목록에서 살펴봅니다. 같은 문서는 정확한 인덱스와 ID가 같을 때만 합칩니다. 검색별 순위는 따로 표시하며 서로 비교하지 않습니다. 근사 벡터 검색은 관련 문서를 놓칠 수 있습니다. 기존 기본 검색과 개념 적용 비교는 그대로 남습니다.

저장한 평가로 검색 방식 비교

같은 질의의 기존 평가를 사용해 개념 적용 BM25와 E5 벡터 결과를 나란히 봅니다. 평가는 바뀌지 않습니다.

같은 정보 요구의 질의 묶음 비교

선택한 저장 질의와 같은 정보 요구 묶음 2~10개를 비교합니다. 질의마다 BM25와 E5 벡터 검색을 함께 실행하며, 최대 20번의 검색 요청이 걸릴 수 있습니다. 진행 중에는 이 버튼을 다시 누를 수 없습니다.

평가한 결과로 설정 비교

개념을 저장하면 평가 준비 상태를 확인할 수 있습니다.

준비 표시는 저장된 학습용 양수 라벨의 존재만 확인합니다. 라벨이 충분하거나 실제 사용을 대표하거나 검색 품질을 보장한다는 뜻은 아닙니다.

실험 기록

저장된 비교와 설정 조정의 실행 결과를 확인합니다.

실험 결과 JSON에는 질의, 문서 ID, 평가 메모와 사유가 포함될 수 있습니다. 공유 전에 내용을 확인하세요.
